# Synthetic Sample Data

All CSV files in this folder are **100% synthetic** and generated by `src/generate_sample.py` using `RANDOM_SEED = 42`.

They match the column schema of CMU CERT r4.2 solely to allow `python main.py` to run end-to-end without redistributing licensed CERT data. Metrics produced on this folder verify code execution only and do not represent performance on the real CERT r4.2 dataset.
